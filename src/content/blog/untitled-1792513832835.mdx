In 2024 I was working with a YC startup that used Webflow for their marketing website, back then, YC startups loved it. I never used it because I preferred to use HTML and CSS, but as they already had it in place I had to use it too.

Holy shit, it was wild. It was a great example of a product made without any compassion. It followed the implementation model of HTML and had nothing to do with how people actually think when they interact with canvas UI.

At some point I exported the code to edit it and the code was even worse. The cherry on top was when we wanted to have a multiplayer feature enabled for two people to work in it simultaneously and they invoiced us $60,000 a year for it.

So I made my own editor that is free, lets people create Astro websites, and if a developer reads its code after export, they want to shake my hand and say "thank you sir".

People can build websites

- By hand, like in Figma.
- Drag and drop components from templates and modify them
- Generate them with AI via MCP, or OpenRouter API.

It has a content management system. This post is written in it. So people also now have a good alternative to Wordpress. It also has SEO settings and Git.

And last but not least, it can deploy websites to Cloudflare, GitHub, Vercel, Netlify.

You run it locally on your machine and own all data, because I live in Europe and don't want to deal with GDPR. It doesn't even have any legit tracking. So I won't be able to track how people use it. But honestly I don't care. Later I will add something.

Since Astro has space motives. Starquix follows the same story line. People can create "stars quickly". I cringe when I think about it, but I really don't want to spend any more time thinking about such insignificant things when the product still doesn't meet my design standards. Done is better than perfect, so here it is.

It's been in a working state for quite a while. This blog post is an MVP of the release. I naively thought I'd be able to prepare a legit release during my vacation in Italy, but that's impossible when you're in Italy. Now that I'm back to Germany there will be better releases soon as winter is coming and I unslopify the UX more and more. Yes, I'm aware it's very bad in some places.

Enjoy!
